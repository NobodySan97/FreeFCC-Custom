# Anonymous Usage Statistics Plan

## Status

Documented for future consideration and postponed. Currently the app sends none of the items described below, and no server endpoint is deployed. The preferred alternative is voluntary diagnostic report sending triggered only by the user: [Voluntary Diagnostic Report Plan](VOLUNTARY_DIAGNOSTIC_REPORT_PLAN.md).

## Purpose

Collect minimal aggregated statistics to understand:

- On which controller and drone models FreeFCC Custom is being used;
- Which Auto FCC mode users select;
- How many installations continue running after updates.

Telemetry must not create a persistent connection, poll hardware solely for statistics, or noticeably consume network, CPU, and battery.

## Proposed In-App Notice

> FreeFCC Custom sends anonymous usage statistics to help improve the app: app version, controller and aircraft models, and the selected mode. Serial numbers, location, logs, and command contents are never sent.

Proposed behavior: statistics opt-out toggle provided in the app.

## What Data May Be Sent

### Installation Profile

Sent after the first successful hardware identification:

- Random `installation_id` generated by the app upon installation;
- App version;
- Controller model code, e.g., `rc331` or `rc520`;
- Aircraft model code, e.g., `WA530`;
- Event format version.

`installation_id` must not be based on Android ID, serial numbers, MAC addresses, or other hardware identifiers. Reinstalling the app generates a new random ID.

### Startup Check-in

At most one brief event created on `BOOT_COMPLETED`:

- `installation_id`;
- App version;
- Selected Auto FCC mode (`home_point_text`, `periodic_5s`, or `off`).

### Mode Selection Event

Created when the user changes the Auto FCC mode in UI or notifications.
